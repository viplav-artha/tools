# tools

A learning repo of general-purpose LLM tools (search, calculator, etc.) built in pure Python
against AWS Bedrock's Converse API, for understanding tool-calling mechanics and future reuse.

## Status

Early stage — being built one file at a time, each with a written walkthrough of why it exists
and how it works. No runnable code yet.
